# ahmetsakalli

Since then, I've moved from development boards to designing my own hardware.

- Hardware debugging and revision analysis
- Camera and sensor integration
- Firmware testing and system validation
- Edge-connected embedded platforms

I am currently developing the Proton AI Core series —
a dedicated embedded hardware platform focused on real-world system integration.
